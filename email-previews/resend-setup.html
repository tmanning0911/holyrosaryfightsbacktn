Resend · Netlify DNS

Email — send & receive on holyrosaryfightsbacktn.com

Domain DNS is on Netlify / NS1 (dns*.p09.nsone.net). Add the domain in Resend, then paste the records Resend shows into Netlify DNS.

Send from: Rams Fight Back <hello@holyrosaryfightsbacktn.com> Receive at: hello@holyrosaryfightsbacktn.com → forwarded to your Gmail Resend is not a full inbox — inbound mail hits a webhook and gets forwarded as a notification.

1. Add the domain in Resend

  1. Open resend.com/domains and sign in.
  2. Click Add Domain.
  3. Enter holyrosaryfightsbacktn.com (root domain — required for noreply@…).
  4. Region: pick closest to US recipients (e.g. us-east-1).
  5. Open the domain’s DNS Records tab and leave it open — you’ll copy three records.

2. Add DNS in Netlify

Netlify → Site → Domain management → holyrosaryfightsbacktn.com → DNS (or Domain management).

Resend will show values like this (copy exactly from your dashboard — do not invent):

TypeName (host)Value
MX send Resend’s feedback-smtp.…amazonses.com · Priority 10
TXT send v=spf1 include:amazonses.com ~all (or whatever Resend shows)
TXT resend._domainkey Long p=… public key from Resend

In Netlify, use only the short host names above (send, resend._domainkey) — do not paste the full send.holyrosaryfightsbacktn.com into the name field.

3. Verify

  1. Back in Resend → click Verify DNS Records.
  2. Usually verifies within 15 minutes (can take longer).
  3. Optional check: dns.email

4. API key for sending

  1. Resend → API Keys → create a key (Sending access).
  2. In Netlify → Site settings → Environment variables add:
RESEND_API_KEY=re_•••••••• RESEND_FROM=Rams Fight Back <hello@holyrosaryfightsbacktn.com> RESEND_REPLY_TO=hello@holyrosaryfightsbacktn.com

Mobilize signup calls POST /api/welcome-send after the Netlify Form saves. Domain must show Verified in Resend.

Optional: DMARC (after verified)

TXT on _dmarc (already live as p=none):

v=DMARC1; p=none;

Start with p=none, tighten later.

5. Receive mail at hello@ (press replies)

  1. Resend → domain → Receiving → enable.
  2. Add the root MX record Resend shows in Netlify DNS (host @ — separate from the rsend send record).
  3. Resend → Webhooks → endpoint https://holyrosaryfightsbacktn.com/api/resend-inbound, event email.received.
  4. Netlify env: RESEND_WEBHOOK_SECRET, INBOUND_FORWARD_TO=taylormanning33@gmail.com.
  5. Deploy, then test by emailing hello@holyrosaryfightsbacktn.com.

Or run node scripts/setup-resend-inbound-webhook.js locally (needs RESEND_API_KEY in .env).
